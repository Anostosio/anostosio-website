CONTEXT / PROBLEM

Job search fragments into dozens of disconnected actions°

Vacancies, statuses, next steps, contacts and rejection reasons quickly spread across tabs and notes. Without one source of context, it becomes harder to prioritise, follow up on time and understand the actual state of the search.

IDEA / SOLUTION

One local workspace instead of scattered lists°

The CRM combines a Today workspace, pipeline, detailed vacancy record, candidate profiles, transparent matcher and local analytics. All workspace data stays in the browser; JSON and CSV give the user direct control over backup and portability.

UX / UI

Action first, analytics second°

The first view surfaces what needs attention today. The pipeline makes movement visible; the detail view preserves evidence and decision history. Analytics is calculated only from the local workspace and never presented as external market data.

AI / HUMAN

An AI-assisted workflow without AI inside the product°

AI supported development through decomposition, implementation options, code review and interface iterations. The CRM itself intentionally does not send vacancies or notes to an LLM and makes no claim of automated AI matching.

RESULT

A working local-first tool°

The CRM is live as a bilingual static application. It supports day-to-day pipeline work, safe data portability, local matching and reporting from the user’s own records. v1.2 has no accounts, cloud sync, AI API or server-side vacancy processing.
