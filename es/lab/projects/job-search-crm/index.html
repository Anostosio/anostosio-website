CONTEXTO / PROBLEMA

La búsqueda de empleo se fragmenta en muchas acciones°

Vacantes, estados, próximos pasos, contactos y rechazos se dispersan entre pestañas y notas. Sin un contexto único resulta más difícil priorizar, hacer follow-up a tiempo y entender el estado real de la búsqueda.

IDEA / SOLUCIÓN

Un workspace local en lugar de listas dispersas°

La CRM combina Today, pipeline, ficha detallada, perfiles de candidato, matcher transparente y analítica local. Todos los datos se quedan en el navegador; JSON y CSV permiten controlar la copia y la portabilidad.

UX / UI

Primero la acción, después la analítica°

La primera vista muestra lo que requiere atención hoy. El pipeline hace visible el movimiento y la ficha conserva evidencia e historial. La analítica se calcula solo con el workspace local y no se presenta como dato externo del mercado.

AI / HUMAN

Flujo asistido por IA sin IA dentro del producto°

La IA apoyó el desarrollo con descomposición, opciones de implementación, revisión de código e iteraciones de interfaz. La CRM no envía vacantes o notas a un LLM y no promete matching automático con IA.

RESULTADO

Una herramienta local-first funcional°

La CRM está publicada como aplicación estática bilingüe. Permite gestionar el pipeline, trasladar datos, analizar coincidencias localmente y crear informes propios. v1.2 no incluye cuentas, cloud sync, AI API ni procesamiento server-side.
