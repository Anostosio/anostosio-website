КОНТЕКСТ / ПРОБЛЕМА

Контекст часто выглядит увереннее, чем он есть°

Бренд-проекты начинаются с разрозненных заметок, предпочтений и неподтверждённых предположений. Обычный AI-ответ может отполировать их так, что пробелы становятся незаметны. В итоге документ выглядит законченным, но плохо помогает принимать решения.

ИДЕЯ / РЕШЕНИЕ

Сделать неопределённость видимой°

Продукт собирает контекст через проектно-зависимую анкету, оценивает готовность входных данных локально и формирует 13 редактируемых разделов. Каждый раздел получает статус доказательности и ссылки на поля-источники; дополнительно система предлагает две различающиеся стратегические траектории как варианты для обсуждения, а не результаты исследования.

UX / UI

UX держится на доверии, а не на магии°

Ключевое решение — не скрывать ограничения модели. Интерфейс объясняет источник каждого вывода, сохраняет работу при ошибке и отделяет AI-результат от локального fallback. Пользователь может проверить, изменить и вынести документ из продукта, не создавая аккаунт.

AI / HUMAN

AI workflow°

Анастасия определила методологию брифа, структуру продукта, UX и правила качества. AI использовался в процессе проектирования и разработки, а внутри самого продукта — как управляемый генератор строго структурированного результата.

  1. 01°

    FRAME

    Определение задачи, границ достоверности и запрещённых выдумок.

  2. 02°

    CONTRACT

    Проектирование JSON Schema и evidence-метаданных для каждого раздела.

  3. 03°

    BUILD

    AI-assisted реализация интерфейса, serverless-функции и состояний отказа.

  4. 04°

    REVIEW

    Повторная валидация ответа, тесты, debugging и проверка двуязычного интерфейса.
