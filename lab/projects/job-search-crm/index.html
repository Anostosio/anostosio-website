КОНТЕКСТ / ПРОБЛЕМА

Поиск работы распадается на десятки несвязанных действий°

Вакансии, статусы, следующие шаги, контакты и причины отказов быстро оказываются в разных вкладках и заметках. Без единого контекста сложнее расставлять приоритеты, вовремя делать follow-up и понимать реальное состояние поиска.

ИДЕЯ / РЕШЕНИЕ

Один локальный workspace вместо разрозненных списков°

CRM объединяет Today workspace, pipeline, подробную карточку вакансии, профили кандидата, прозрачный matcher и локальную аналитику. Все рабочие данные остаются в браузере; JSON и CSV дают пользователю контроль над резервной копией и переносом.

PRODUCT

Рабочий контур°

01

TODAY

Просроченные контакты, ближайшие действия и текущие приоритеты в одном экране.

02

PIPELINE

Board и Table для активных и архивных этапов.

03

VACANCY DETAIL

Данные отклика, match evidence, контакты, заметки и история действий.

04

MATCHER

Прозрачные локальные правила показывают совпадения и пробелы; текст вакансии не уходит в AI-сервис.

05

DATA SAFETY

JSON backup, CSV export, import preview, Merge/Replace, safety backup и undo удаления.

06

DUPLICATES

Проверка нормализованной ссылки и сочетания company + role.

UX / UI

Сначала действие, затем аналитика°

Первый экран собирает то, что требует внимания сегодня. Pipeline показывает движение вакансий, а detail-view хранит доказательства и историю решения. Аналитика считается только из локальной воронки и не выдаётся за внешние данные рынка.

AI / HUMAN

AI workflow без AI внутри продукта°

AI использовался как инструмент разработки: для декомпозиции, вариантов реализации, проверки кода и итераций интерфейса. Сам CRM намеренно не отправляет вакансии или заметки в LLM и не обещает автоматическую AI-оценку.

  1. 01°

    FRAME

    Определение ежедневного workflow, статусов и границ local-first продукта.

  2. 02°

    MODEL

    Проектирование схемы вакансии, истории, профилей и безопасного импорта.

  3. 03°

    BUILD

    AI-assisted реализация модулей хранения, matcher, интерфейса и export flows.

  4. 04°

    VERIFY

    Тесты миграции, нормализации, импорта, формул CSV и статического build.

РЕЗУЛЬТАТ

Рабочий local-first инструмент°

CRM опубликован как двуязычное статическое приложение. Он поддерживает ежедневную работу с воронкой, безопасный перенос данных, локальный matcher и отчётность по собственным записям. Аккаунтов, cloud sync, AI API и серверной обработки вакансий в v1.2 нет.
